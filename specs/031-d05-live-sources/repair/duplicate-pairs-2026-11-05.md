# Duplicate matches from YallaKora's first runs, 2026-11-05

For review before `repair-matches merge --apply`. The command reads
[duplicate-pairs-2026-11-05.json](duplicate-pairs-2026-11-05.json), and the steps are in
[imports-and-sources.md](../../../docs/runbooks/imports-and-sources.md#merging-duplicate-matches).

Runs 143 and 177 created 76 rows. **74 are copies** of a row we already held, and 2 are real fixtures only YallaKora has. Each pair keeps the older row, which has the channels, and takes the copy's score, links and broadcaster. Pairs came from production on 2026-11-05 (same kickoff window, closest names) and were then read by hand.
