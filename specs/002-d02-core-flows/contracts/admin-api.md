# Contract: admin API, D2 additions (`/admin/api`)

Part of `app.admin:app`, exported as `backend/openapi/admin.json`. These additions are **non-breaking against `contract-v1`**, and `backend.yml`'s oasdiff check must pass. `/v1` (`public.json`) doesn't change.

B1 merges the routes, shapes and Prism examples below, with stub handlers, **by 13:00**. The same PR carries the admin client and Zod schemas regenerated by Orval from the new `admin.json` (D14), because `backend.yml`'s `clients` job fails on a stale client. Lane A then builds on that client from `master`. No new tag is cut.

Sources: SD §6.4, §6.5, §6.9; PB §10 A3, A4; spec FR-001 to FR-014; [research](../research.md) R1–R12.

## Conventions

- **Envelope, errors, times and ids** follow D1 ([public-api-v1.md](../../001-d01-foundation/contracts/public-api-v1.md)), and the auth routes are exactly D1's [admin-auth-v1.md](../../001-d01-foundation/contracts/admin-auth-v1.md).
- **Auth:** every route below needs `Authorization: Bearer <access_token>`, plus the role in its row. `admin` includes `editor`.
- **Versions:**
  - a single-entity `GET`, and every write response, carry `ETag: "<32 hex>"` (strong; [research R5](../research.md#r5-entity-versions-and-if-match));
  - every `PATCH` and `DELETE`, and every item of a bulk request, needs `If-Match` (header or item field) with that value;
  - creates (`POST` of a new entity) and the hidden-name add and remove take no `If-Match` (plan, Complexity Tracking).
- **List ETags:** list `GET`s return a weak `ETag` built from `dataset_versions` and the query (D1 R4), and answer a matching `If-None-Match` with `304`.
- **Media fields** come in pairs: the `*_asset_id` to write, and the absolute `*_url` (or `logo`, `photo`, `audio`) to show.
- **Admin times** are UTC instants. A3 and A4 convert to and from Cairo time on the client ([research R24](../research.md#r24-session-forms-and-time-in-the-admin)).
- **Content:** every free-text field that reaches `/v1` (entity names, `display_name`, `provider`, `package`, `competition_stage`, `stadium`, a team or competition sent as text, broadcaster `label`, `status_label`) is refused with `422 validation_error` when it holds a card-sharing label (`Mega Share`, `Apollo`, `VIP`, «ليست مكسورة», `BISS`, matched as whole words; O3, constitution "Content and legal").

### Errors added on D2

| Status | `error.code` | When | `meta` |
| --- | --- | --- | --- |
| 401 | `unauthenticated`, `token_expired` | D1 codes, now enforced on every route | — |
| 403 | `forbidden` | the role is below the route's requirement | `required_role` |
| 404 | `match_not_found`, `team_not_found`, `competition_not_found`, `satellite_not_found`, `channel_not_found`, `commentator_not_found`, `hidden_name_not_found` | unknown id | — |
| 409 | `edit_conflict` | `If-Match` is stale | `current_etag`, `changed_by: {kind: "admin" \| "source", name}`, `changed_at`; for bulk, `stale_ids` |
| 409 | `in_use` | deleting an entity something still references | `usage: {matches, channels, teams, …}` |
| 409 | `already_exists` | a unique rule fails (an email, a satellite slug, a competition per sport and name, a channel carriage) | `field` |
| 413 | `file_too_large` | an upload over its cap | `max_bytes` |
| 415 | `unsupported_media_type` | the magic bytes aren't an allowed type for `kind` | — |
| 422 | `validation_error` | as on D1, now including the manual-status rules (data-model) | `errors[]` |
| 422 | `media_invalid` | the file won't decode, or the audio has no readable stream | — |
| 428 | `precondition_required` | a write without `If-Match` | — |

**Rules**, from [data-model](../data-model.md) and [research R7–R8](../research.md#r7-the-match-editors-payload):

- **Link changes:**
  - a link left out of `channels` is deleted if `imported_by` is null, and otherwise kept as hidden `manual`;
  - a link whose hidden flag or commentators changed becomes `manual`.
- **Validation:** `competition_name` is required when `competition_id` is null. `home` and `away` take exactly one of `team_id` or `name`. Up to 300 links, and up to 200 bulk items.
- **Bulk:** all or nothing. A stale item gives `409 edit_conflict` with `meta.stale_ids`.
- **Examples (Prism):** `match_ok`, `edit_conflict` (409, `changed_by` an admin), `edit_conflict_source` (409, `changed_by: {kind: "source", name: "ysscores"}`), `precondition_required` (428), `forbidden_remove_channels` (403), `validation_error_status` (422: a score on `postponed`).

## Teams, competitions, satellites, channels, commentators

Every write follows the same rules: `If-Match` on `PATCH` and `DELETE`, an audit entry, version bumps, and `locked_fields` on channels.

| Method & path | Role | Notes |
| --- | --- | --- |
| `GET /teams?q&competition_id&missing_logo&cursor&limit` | editor | With `q`: the top 20 by similarity, `next_cursor: null`. Without `q`: keyset pages, `limit` ≤ 100. Items are `TeamItem` |
| `GET /teams/{id}` · `POST /teams` · `PATCH /teams/{id}` · `DELETE /teams/{id}` | editor | `AdminTeam`. `DELETE` → `409 in_use` while a match or follow references the team |
| `GET /competitions` · `GET /competitions/{id}` · `POST` · `PATCH` · `DELETE` | editor | Whole list, ordered by `priority` (nulls last), then `name`. `AdminCompetition` |
| `GET /satellites` · `GET /satellites/{id}` · `POST` · `PATCH` · `DELETE` | editor | Whole list. `AdminSatellite`. `DELETE` → `409 in_use` while channels reference it |
| `GET /channels?q&satellite_id&category&kind&access&missing_logo&cursor&limit` | editor | Keyset pages on `(sort_order, id)`; with `q`, the top 20. `ChannelItem` |
| `GET /channels/{id}` · `POST /channels` · `PATCH /channels/{id}` · `DELETE /channels/{id}` | editor | `AdminChannel`. `DELETE` is a soft delete (`deleted_at`) |
| `GET /commentators?q&cursor&limit` · `GET /commentators/{id}` · `POST` · `PATCH` · `DELETE` | editor | `AdminCommentator`. `DELETE` → `409 in_use` with the usage count |

## Media

| Method & path | Role | Request | Response |
| --- | --- | --- | --- |
| `POST /media` | editor | `multipart/form-data`: `kind` (`image` \| `audio`), `file` | `201` new, or `200` already stored: `{id, kind, url, width, height, duration_ms, bytes}` |

- Caps: images ≤ 2 MB, audio ≤ 1 MB.
- The type is decided by magic bytes, never by the file name or `Content-Type` ([research R10](../research.md#r10-uploads)).
- Output: WebP ≤ 512 px with metadata stripped, or AAC in MP4 trimmed to 30 s.
- The response has no `ETag`, because there's nothing to version: the asset is immutable and content-addressed.
- **Examples:** `media_ok`, `file_too_large` (413), `unsupported_media_type` (415), `media_invalid` (422).
