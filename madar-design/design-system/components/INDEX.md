# Component index

Every reusable component in the design, with where it is specified. Each folder has a `README.md` (purpose, anatomy, states, rules, the Flutter widget or React component name, and the CSS classes that draw it in the screen HTML), a static `preview.html` and dark and light screenshots.

When a screen HTML file uses one of the CSS classes below, it is an instance of that component: build it once as a widget or component and reuse it.
